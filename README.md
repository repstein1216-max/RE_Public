# RE_Public

Public real estate analytics resources, including Power BI dashboards, sample datasets, and documentation.

## Contents

| Folder | Description |
|--------|-------------|
| [PowerBI/](./PowerBI/) | Power BI report documentation, templates, and sample data |

## Power BI Dashboards

This repository contains resources for the following Power BI reports:

1. **Real Estate Market Overview** – High-level KPIs: median sale price, days on market, list-to-sale ratio, and active listing counts.
2. **Property Sales Analysis** – Drill-through analysis by property type, bedroom count, and neighborhood.
3. **Price Trends** – Month-over-month and year-over-year price trends with forecasting.
4. **Rental Market Summary** – Rental vacancy rates, average rent per square foot, and rental yield by area.

## Getting Started

1. Clone or download this repository.
2. Open the `.pbix` file in [Power BI Desktop](https://powerbi.microsoft.com/en-us/desktop/) (free download).
3. Replace the sample data source with your own data, or use the included CSV files in `PowerBI/data/`.
4. Publish to [Power BI Service](https://app.powerbi.com/) to share with others.

## Data Sources

Sample datasets are provided in CSV format under `PowerBI/data/`. See the [Data Dictionary](./PowerBI/DATA_DICTIONARY.md) for field definitions.
